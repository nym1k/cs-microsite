# cs-microsite — Project Overview

## About
Microsite for Countless Skies (countlessskies.com). Static HTML/CSS/JS site hosted on GitHub Pages.

## Stack
- HTML (index.html — single-page site)
- SCSS → CSS via node-sass (`npm run dev`)
- Vanilla JS (`js/`)
- Hosted on GitHub Pages with custom domain via CNAME

## Directory Structure
```
index.html        # Main page
css/              # Compiled CSS
sass/             # SCSS source
js/               # JavaScript
img/              # Images
```
